# Hello World module

Placeholder module that confirms the plugin is deployed and booting correctly. Remove it once real modules are in place.

## What it does

- Shows a green admin notice to administrators: `Hello World from Rowdy Crowd (vX.Y.Z)`.
- Registers the `[rowdy_crowd_hello]` shortcode, which outputs the same message on the front end.
